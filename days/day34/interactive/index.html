Make Your Automation Explain Itself.

A script that runs unattended must leave evidence. Today you will use Python's built-in logging module, meaningful log levels, readable formats, and durable log files.

Why operations teams care

Cron, Task Scheduler, CI jobs, and monitoring scripts often run without an operator watching. Logs preserve what happened, when it happened, and why a decision was made.

TRACE

Leave an execution trail

Record workflow starts, completed steps, counts, decisions, warnings, failures, and final outcomes for later investigation.

PRIORITISE

Use meaningful severity

DEBUG, INFO, WARNING, ERROR, and CRITICAL help operators separate normal progress from conditions requiring attention.

PERSIST

Write durable log files

Use handlers and formatters to send detailed records to UTF-8 files while keeping console output focused.
