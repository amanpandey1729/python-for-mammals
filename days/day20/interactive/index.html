What you will learn

Day 20 completes the basic file-handling loop: read input, process it, and write useful output that someone can review later.

Concept 1

write()

Save text into a file so your script can produce reusable output instead of only printing on screen.

Concept 2

Write mode

Create a new file or replace an existing file when generating a fresh report.

Concept 3

Append mode

Add new lines at the end of an existing file without deleting previous content.

Concept 4

New lines

Use \n correctly so each report entry appears on its own readable line.

Concept 5

Variables in reports

Write values from variables, calculations, conditions, and lists into text files.

Concept 6

Report creation

Build clean operational summaries for health checks, disk usage, inventory, and daily activity.
