Why operations teams care

Linux already exposes disk, memory, load, and process information through trusted commands. Python makes those results reusable by parsing text into numbers, lists, dictionaries, alerts, and reports.

Collect

Run Familiar Commands

Use subprocess.run() to capture read-only output from df, free, uptime, and ps.

Process

Extract Useful Values

Split rows and columns, remove percentage signs, convert text to numbers, and store process details as dictionaries.

Decide

Apply Operational Thresholds

Compare disk, memory, and process values with thresholds to produce HEALTHY or ATTENTION decisions.
