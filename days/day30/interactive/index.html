Use Python's subprocess module to run safe external commands, capture standard output and errors, inspect return codes, and build reliable command checks.

Why operations teams care

Many health checks, inventory tools, diagnostics, and administrative utilities already exist as commands. subprocess lets Python run them, capture their results, and make decisions using return codes, stdout, and stderr.

Run

Execute External Tools

Use subprocess.run() with an argument list to call a program safely and wait for it to finish.

Capture

Read Command Results

Use capture_output=True and text=True to work with stdout and stderr as normal strings.

Decide

Evaluate Success

Inspect returncode, add timeouts, and handle failed or missing commands without crashing the workflow.
