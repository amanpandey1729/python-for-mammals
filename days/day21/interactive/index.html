What you will learn

Day 21 makes your scripts safer by teaching them what to do when input, files, calculations, or dictionary keys are not perfect.

Concept 1

try

Place risky code inside try so Python can watch for problems without immediately stopping the script.

Concept 2

except

Respond to a specific error with a clear message or alternate action.

Concept 3

else

Run success logic only when the try block completes without an exception.

Concept 4

finally

Run cleanup or final messages whether the try block succeeds or fails.

Concept 5

Common errors

Recognize ValueError, ZeroDivisionError, FileNotFoundError, KeyError, and IndexError.

Concept 6

Safe workflows

Protect input conversion, file reading, calculations, dictionary access, and report generation.
